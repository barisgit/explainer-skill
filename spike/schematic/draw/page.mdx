# Schematics drawn element by element

Schemdraw's way: each element starts where the last ended unless `at` moves it, and runs in a direction for a length or to an anchor. The <span data-ref="R_SC">sense resistor</span> and the <span data-ref="R3">R3</span>/<span data-ref="R4">R4</span> divider set the fold-back knee.
