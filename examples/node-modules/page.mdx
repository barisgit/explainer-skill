## Production

In production, express needs {tree("express").count} packages and {MB(tree("express").bytes)}. Listed as dependencies, eslint and jest install on every server, though only linting and tests use them. Moved to `devDependencies`, they stay out of `npm install --omit=dev`, which then installs express's own {tree("express").onlyCount} packages and the {tree("express").count - tree("express").onlyCount} it shares: {Math.round((tree("express").bytes / TOTAL) * 100)}% of the bytes.
